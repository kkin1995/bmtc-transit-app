<objective>
Fix the variance divisor bug (BUGFIX-05): `compute_variance()` currently returns population variance `m2/n` but is documented and used as sample variance. Change it to the Bessel-corrected sample formula `m2/(n-1)` for `n >= 2`, preserving the existing `n < 2` guard exactly.

Per BUGFIX-05 and ROADMAP Phase 2 success criterion #2: after 10 observations the P90 bound must be measurably wider than with the population formula. This is a one-line divisor change plus three new golden-value unit tests.

Purpose: Systematically narrow P90 bounds under-estimate travel-time upper bounds, degrading ETA reliability for riders. The sample formula is the canonical statistical convention paired with Welford's algorithm when observations are a sample of a larger population (travel times are).

Output: One-line change in `learning.py::compute_variance`, three new passing unit tests in `test_learning.py`.

This plan is intentionally isolated and first (Wave 1): it is low-risk, touches only a pure function, and its regression test locks the `n < 2` guard that the later BUGFIX-04 seed path depends on (RESEARCH.md Pitfall #2).
</objective>
