<objective>
Deliver OPS-04: structured, per-request JSON logging so an operator can observe latency and derive
error rate from logs alone — zero new dependencies (D-15, D-16).

Purpose: Make production latency/error rates observable via one JSON object per request line
(`request_latency_ms`, `method`, `path`, `status`), parseable by `journalctl -u bmtc-api | jq`.
`error_rate` is DERIVED by the operator (`count(status>=400)/count(*)`), not emitted as a field (D-18).
Output: new `backend/app/logging_config.py` (`JsonFormatter` + `configure_logging`), a `TimingMiddleware`
added to `backend/app/main.py`, tests in `backend/tests/test_timing_middleware.py`, and a systemd
tweak to avoid duplicate (uvicorn access log) lines.

Applies three verified RESEARCH corrections to CONTEXT.md's rationale text:
- #2 (Pitfall 2): TimingMiddleware must be added LAST in main.py to be outermost (Starlette reverses
  add_middleware order) — NOT "first" as D-17's rationale text literally says.
- #3 (Pitfall 3): the root logger currently has NO handlers and defaults to WARNING; an explicit
  `configure_logging()` step is REQUIRED or every `logger.info()` silently emits nothing.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → API (ASGI middleware) | Untrusted request metadata (method, path) is logged; must not log secrets or user-influenced content unescaped |
| API process → log stream (journald) | Log lines are consumed downstream by operators/tools; a crafted `path` could attempt log injection |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-03 | Information Disclosure | TimingMiddleware log line | high | mitigate | Log only method, `request.url.path`, status, latency — never the Authorization header, request body, or query string; matches CLAUDE.md "no request payloads at INFO; avoid IP linkage" (ASVS V7) |
| T-05-04 | Tampering | log injection via crafted `path` (embedded newlines/quotes forging fake JSON fields) | medium | mitigate | Emit the line via `json.dumps()` (Pattern 4), which escapes control characters — one of the stated reasons D-16 chose real JSON over logfmt |
| T-05-05 | Denial of Service | a raising formatter crashes request logging | low | mitigate | `JsonFormatter` uses `default=str` and never raises; TimingMiddleware logs in `finally` so it cannot swallow/alter the response |

*No new packages introduced (RESEARCH Package Legitimacy Audit: zero new dependencies), so no supply-chain (T-*-SC) checkpoint applies.*
</threat_model>
