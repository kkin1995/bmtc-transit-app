<objective>
Harden the application bootstrap in three related, main.py-centric fixes that were deliberately sequenced after Plan 01 rewrote every `routes.py` connection call site:

1. BUGFIX-02 (CORS): Replace `allow_origins=["*"]` + `allow_credentials=True` with an explicit allowlist sourced from a new `BMTC_CORS_ORIGINS` setting, and remove `allow_credentials` entirely (Bearer-header auth only, no cookies) — eliminating the wildcard-origin + credentials combination browsers reject and Starlette silently degrades to origin-reflection (D-01 through D-05).
2. BUGFIX-07 (startup cleanup): Call the already-existing `cleanup_expired_keys()` in the lifespan handler after `init_db()` so expired idempotency keys are purged on every startup (locked by ROADMAP success criterion #4).
3. LEARN-03 (dead code): Delete the unused `slowapi` `Limiter` instances, imports, and exception-handler wiring from `main.py` and `routes.py`, and remove the `slowapi` dependency line from `pyproject.toml` — `RateLimitMiddleware` is the sole active rate limiter.

Purpose: Remove a production-security misconfiguration (CORS), an operational reliability gap (unbounded idempotency table growth), and a second competing rate-limit mechanism (dead code) — all concentrated in `main.py`.
Output: `config.py` cors_origins field, `main.py` CORS/lifespan/slowapi edits, `routes.py` slowapi removal, `pyproject.toml` dependency removal, and two new tests (CORS behavior, startup-invocation).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser→API (CORS) | The `Origin` request header is attacker-influenceable; CORS policy decides which origins may read responses |
| client→API (idempotency table) | Untrusted clients drive idempotency-key rows; unbounded growth is an availability concern |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-CORS | Tampering / Information Disclosure | `main.py` CORSMiddleware config | high | mitigate | Explicit origin allowlist from `BMTC_CORS_ORIGINS` + full removal of `allow_credentials` (D-01..D-05) — eliminates the wildcard-origin+credentials combination Starlette degrades to origin-reflection; canonical OWASP/ASVS V14.4 CORS-misconfiguration fix (BUGFIX-02) |
| T-02-Growth | Denial of Service | `idempotency_keys` table | medium | mitigate | Invoke `cleanup_expired_keys()` at lifespan startup so expired rows do not accumulate unbounded (BUGFIX-07) |
| T-02-DeadCode | Tampering | `slowapi` Limiter dead code | low | mitigate | Delete the unused second rate-limit mechanism so future edits cannot accidentally wire it and create conflicting/silently-disabled limiting (LEARN-03) |
| T-02-SC | Tampering | pip dependency set | low | accept | This plan REMOVES an already-vetted, already-installed dependency (`slowapi==0.1.9`); it installs nothing new — no supply-chain surface added. |
</threat_model>
