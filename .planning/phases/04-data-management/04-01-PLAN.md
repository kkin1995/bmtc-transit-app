<objective>
Establish the versioned DB migration framework required by DATA-01: archive the four orphaned Oct-2025 migration files as historical record (D-01), add a `schema_migrations`-tracked diff-and-apply runner (`apply_migrations.sh`, D-02), and seed `schema_migrations` on fresh bootstrap so a freshly-created DB never double-applies changes `schema.sql` already contains (RESEARCH.md Pitfall 1).
